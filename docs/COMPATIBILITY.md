# 升级与兼容

## 支持范围

Tidal 当前版本为 **0.1.3**，插件清单声明兼容 Zotero **7.0–10.0.x**。

已有原生验证记录来自 **macOS + Zotero 10.0.7**，覆盖安装、升级、阅读抽屉、设置、历史及缓存复用。其他系统和 Zotero 版本仍需实测。段落定位使用阅读器内部接口，清单中的版本范围不代表所有平台都已验证。

当前未提供自动更新服务，请从仓库 Releases 下载 XPI，通过 Zotero 的插件管理器手动安装。

## 保留旧版配置

Tidal 从 0.1.0 开始使用当前名称。为保留旧版配置、凭证及历史，以下内部标识继续沿用：

| 内容 | 内部标识 |
| --- | --- |
| 扩展 ID | `paper-translator@local.invalid` |
| 配置及抽屉偏好 | `extensions.paper-translator.*` |
| 登录管理器凭证入口 | `chrome://paper-translator`，按服务地址绑定 |
| Zotero 数据目录中的任务缓存 | `paper-translator/` |

界面、菜单和安装包均显示 **Tidal**。升级时请直接安装新 XPI，不需要删除配置或缓存。

## 历史与任务

- 相同附件的 PDF 内容不变时，优先复用已有历史；修改默认设置不会重新发起解析或翻译。
- 历史任务继续使用创建时的语言、模型及翻译策略。打开未完成历史不会自动续跑，需手动重试未完成段落。
- 要按新设置重新翻译，或补充旧任务缺失的段落坐标，请先在历史中删除对应记录，再从 PDF 启动。删除有确认步骤，原 PDF 与已保存到 Zotero 的附件、笔记保留。
- 旧任务没有段落坐标时，仍可阅读、复制和导出；无法可靠定位到 PDF。
- 0.1.2 起，原始定位 JSON 在校验后转换为精简索引。过程文件清理保留阅读所需内容，并跳过活动任务。
- 0.1.3 调整阅读工具栏与菜单，沿用原有任务身份和历史格式。
