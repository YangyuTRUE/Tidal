高级选项

通常保持默认值即可。较低的并发数适合容易限流的服务。

每个任务固定语言、模型和分块配置。修改设置后请从 PDF 重新启动；旧任务的“继续”仍使用创建时配置。凭证按服务地址分别保存，修改端点后需填写对应凭证。

全文翻译会将 PDF 发送到 MinerU，解析文本发送到你配置的翻译服务；选区翻译只发送选中文字。服务可能产生 API 费用，凭证保存在 Zotero 登录管理器中。
